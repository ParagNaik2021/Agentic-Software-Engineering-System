# Agentic SDLC Orchestration System

A stateful, governed, non-linear orchestration engine that drives requirements
through to release readiness using specialised agents, generating a
production-shaped URL Shortener service as its target application.

> Status: under active build, phase P0 (scaffolding) complete. Full setup and
> quickstart instructions land in P9 (see `docs/engineering-summary.md` and
> Section 14 of the implementation plan once populated).

## Quick look

```
pip install -e ".[dev,target]"
agentic --help
```

See `docs/architecture.md` for the system design once P9 lands.
