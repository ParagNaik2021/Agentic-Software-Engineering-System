# Agentic Software Engineering System

This repository contains a single project.

**All code, documentation, and setup instructions are inside the
[`agentic-sdlc/`](./agentic-sdlc) folder.**

Start here: [`agentic-sdlc/README.md`](./agentic-sdlc/README.md)

## What's in `agentic-sdlc/`

A stateful, governed, non-linear orchestration engine that drives a
software requirement through requirements analysis, design,
implementation, verification, documentation and release readiness using
specialised agents — demonstrated across three scenarios (greenfield,
brownfield, ambiguous) that generate and extend a URL Shortener service
as the target application.

See [`agentic-sdlc/README.md`](./agentic-sdlc/README.md) for setup,
the CLI reference, and step-by-step instructions to run each scenario.
